# results — 측정 기록

실행할 때마다 `<날짜>-<실험명>/` 폴더를 만들고 그 안에 남긴다. 예: `2026-08-01-volume/`

```
2026-08-01-volume/
├── summary.md        계단별 비교 표. 사람이 읽는 결론
├── step-1.json       계단별 원시 측정값
├── …
└── raw/              k6 원시 출력. gitignore 대상
```

## summary.md 에 담을 것

| 계단 | 상품 | DB 크기 | 목록 p95 | 검색 p95 | 카테고리 p95 | 히트율 | 판정 |
|---|---|---|---|---|---|---|---|

- **판정은 1계단 대비 상대 악화**로 적는다. 절대값은 참고로만 — 이 호스트의 수치는
  다른 환경과 비교할 수 없다(README의 "왜 볼륨 테스트인가" 참고)
- 계단마다 **무엇이 달라졌는지 한 줄**을 같이 적는다. 숫자만 남기면 나중에 못 읽는다
- 중간에 설정을 바꿨으면(버퍼풀·인덱스 등) **반드시 기록한다.** 조건이 달라진 측정을
  같은 표에 섞으면 표 전체가 무의미해진다

## 왜 커밋하는가

"인덱스 추가 전후", "버퍼풀 확대 전후" 같은 비교는 **이전 측정이 남아 있어야** 성립한다.
요약본만 커밋하고 원시 로그는 제외해 리포가 무거워지는 것을 막는다.
