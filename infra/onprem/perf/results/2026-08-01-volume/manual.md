# 수동 실측 — 계단 1 (상품 10,006건)

실행 폴더에 `manual.md` 로 복사해 쓴다. 자동 수집(`step-N.json`)이 못 보는 것을 사람이 채운다 —
**서버가 몇 ms 걸렸는가**와 **사용자가 느리다고 느끼는가**는 다른 질문이다.

## 측정 조건 (계단마다 동일하게 유지할 것)

조건이 흔들리면 계단 간 비교가 통째로 무의미해진다. 매번 아래를 지킨다.

- [ ] DevTools → Network → **Disable cache 체크**
- [ ] 측정 전 해당 화면을 한 번 열어 워밍업(그 값은 버린다)
- [ ] 항상 같은 순서로: 목록 → 검색 → 카테고리 → 상세
- [ ] 다른 무거운 작업(빌드·부하 스크립트) 동시에 돌리지 않기
- [ ] 브라우저 창 크기 고정 (렌더링 시간에 영향)

**API 응답**: Network 탭에서 해당 `/api/...` 요청의 Time
**화면 완료까지**: 눈으로 "다 그려졌다" 싶은 시점. 정확할 필요 없다 — 체감과 짝으로 본다

## 체감 척도

| 표기 | 뜻 |
|---|---|
| 즉시 | 기다린다는 느낌이 없다 |
| 살짝 | 멈칫하지만 거슬리지 않는다 |
| 눈에 띄게 | 기다리고 있다는 자각이 든다 |
| 못 쓰겠음 | 다시 누르거나 이탈할 것 같다 |

**체감이 꺾이는 계단이 이 실험의 답이다.** 숫자만 남기면 "몇 ms 부터 문제인가"를 나중에 못 정한다.
